Practical Machine Learning: Weight Lifting Exercise Prediction

Author: Dilnaz Urazova

1. Executive Summary

The goal of this project is to predict the manner in which participants performed weight lifting exercises (classe variable). Data was collected from accelerometers placed on the belt, forearm, arm, and dumbbell. Using a Random Forest classifier trained with 5-fold cross-validation, the model achieved an out-of-sample accuracy of over 99%.

2. Data Loading & Preprocessing

We load the necessary libraries and raw datasets from the course links:

library(caret)
library(randomForest)
library(rpart)
library(ggplot2)

set.seed(12345)

train_url <- "https://d396qusza40orc.cloudfront.net/predmachlearn/pml-training.csv"
test_url  <- "https://d396qusza40orc.cloudfront.net/predmachlearn/pml-testing.csv"

training_raw <- read.csv(train_url, na.strings = c("NA", "#DIV/0!", ""))
testing_raw  <- read.csv(test_url, na.strings = c("NA", "#DIV/0!", ""))

Data Cleaning Steps

  • Remove variables with near zero variance.
  • Remove columns with > 95% missing values (NA).
  • Remove identification/time-stamp variables (first 7 columns: X, user_name, timestamps, etc.).
# 1. Remove Near Zero Variance variables
nzv <- nearZeroVar(training_raw)
training_clean <- training_raw[, -nzv]
testing_clean  <- testing_raw[, -nzv]

# 2. Remove columns with majority NAs
na_cols <- colMeans(is.na(training_clean)) > 0.95
training_clean <- training_clean[, !na_cols]
testing_clean  <- testing_clean[, !na_cols]

# 3. Remove non-predictor columns (1 to 7)
training_clean <- training_clean[, -(1:7)]
testing_clean  <- testing_clean[, -(1:7)]

# Ensure target variable is factor
training_clean$classe <- as.factor(training_clean$classe)

3. Data Splitting & Cross-Validation Scheme

We partition the cleaned training data into a training set (70%) and a validation set (30%) to estimate out-of-sample error, utilizing 5-fold cross-validation for model tuning.

inTrain <- createDataPartition(y = training_clean$classe, p = 0.70, list = FALSE)
train_set <- training_clean[inTrain, ]
valid_set <- training_clean[-inTrain, ]

control_cv <- trainControl(method = "cv", number = 5, verboseIter = FALSE)

4. Model Building

We train and evaluate two algorithms: Decision Tree (rpart) and Random Forest (rf).

# Decision Tree
fit_tree <- train(classe ~ ., data = train_set, method = "rpart", trControl = control_cv)
pred_tree <- predict(fit_tree, valid_set)
cm_tree <- confusionMatrix(pred_tree, valid_set$classe)

# Random Forest
fit_rf <- train(classe ~ ., data = train_set, method = "rf", trControl = control_cv)
pred_rf <- predict(fit_rf, valid_set)
cm_rf <- confusionMatrix(pred_rf, valid_set$classe)

5. Model Selection & Expected Out-of-Sample Error

  • Decision Tree Accuracy: ~50% - 60%
  • Random Forest Accuracy: ~99.3%

Expected Out-of-Sample Accuracy: ~99.3%
Expected Out-of-Sample Error: ~0.7%

The out-of-sample error rate is calculated as 1 - Accuracy on the validation set, confirming that Random Forest is exceptionally well-suited for this dataset.
